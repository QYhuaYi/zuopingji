# 骆捷 · 个人作品集

基于原生 HTML / CSS / JavaScript 构建的个人作品集单页网站，用于展示个人介绍、技能方向与项目作品。

## 主要功能

- **个人介绍**：首屏大标题排版，展示身份、院校、求职意向与技能关键词
- **项目作品**：数据驱动的杂志式项目展示，支持 4 种版式与 5 种图片比例，新增项目只需修改 `js/projects.js` 数据
- **关于我**：技能清单与个人优势介绍
- **联系方式**：邮箱、电话、求职意向等信息
- **深浅色主题切换**：导航栏按钮一键切换，`localStorage` 记忆用户选择，刷新不丢失
- **响应式布局**：桌面 12 列栅格 → 平板单列 → 手机单列，移动端配备折叠式导航菜单

## 技术栈

- HTML5 + CSS3（CSS 变量、Grid 栅格、clamp 流式缩放）
- 原生 JavaScript（ES5 风格，无框架、无第三方库、无构建工具）

## 运行方式

纯静态站点，无需安装依赖：

- **直接打开**：双击 `index.html` 即可在浏览器中查看
- **本地服务器**（推荐，体验完整功能）：

  ```bash
  # Python
  python -m http.server 8080
  # 或 Node.js
  npx serve .
  ```

  然后访问 `http://localhost:8080`

## 目录结构

```
├── index.html          # 页面结构
├── css/
│   ├── base.css        # 变量（含深色主题）、重置、通用样式
│   ├── layout.css      # 导航、首屏、关于我、联系方式、页脚
│   ├── projects.css    # 项目展示区（4 种版式）
│   └── responsive.css  # 断点适配
└── js/
    ├── projects.js     # 项目数据（唯一数据源）
    └── main.js         # 渲染、导航、菜单、主题切换等交互
```
